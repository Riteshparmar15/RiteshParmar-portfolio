# Ritesh Parmar — DOT NET Backend Developer Portfolio

Interactive 3D WebGL developer portfolio built with Three.js, C# / DOT NET architecture themes, and modern responsive design.

🌐 **Live Demo:** [https://riteshparmar15.github.io/RiteshParmar-portfolio/](https://riteshparmar15.github.io/RiteshParmar-portfolio/)

---

## 🛠️ Tech Stack & Highlights

- **Backend Specialization:** C#, ASP.NET Core, Entity Framework Core, MySQL, Microservices, High-Throughput REST APIs
- **Frontend & 3D Interactive:** Three.js (r185), WebGL 3D cylinder carousel, Canvas animations, Lenis smooth scrolling
- **Design System:** Sleek dark aesthetics, custom SVG masks, fluid responsive layout for mobile and desktop

---

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/Riteshparmar15/RiteshParmar-portfolio.git
cd RiteshParmar-portfolio

# Start local server
npm start
# or: npx serve -s -p 4173 .
```

Open [http://localhost:4173](http://localhost:4173) in your browser.
